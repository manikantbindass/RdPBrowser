Lockfile-compatible security updates include Axios 1.21.1, Express 4.22.1, Socket.io parser 4.2.7 and ws 8.21.3. Patched qs is pinned via override 6.16.2. Removed unused http-proxy-middleware, morgan, node-cron and uuid after source-reference inspection; core crypto UUIDs and the existing interval worker remain. Development-only OpenAPI validator @apidevtools/swagger-parser 13.1.0 requires Node >=22.19; CI Node22 resolves current patch, host checks use Node24.14.1. No runtime stack replacement was introduced.

Production audit before: 18 package findings (1 critical, 10 high, 7 moderate). After: 2 (1 high ip-address, 1 moderate inherited geoip-lite). The vulnerable ip-address module is imported by GeoIP's optional database update script, not its runtime lookup path. Do not run that updater on untrusted datasets. GeoIP 2.0.3 requires Node24; a forced major/overridden parser API update was not assumed compatible with Node22 or its legacy updater. Remediation requires a verified compatible GeoIP/parser migration or documented Node upgrade. Current local packaged lookup is retained; geolocation is an approximate control, not identity.

Full backend audit after also reports development-only deepmerge/Jest and minimatch/nodemon chains; total 10 package findings (6 low, 3 moderate, 1 high). No audit gate was disabled and no forced Jest downgrade was applied. Machine-readable before/after/full snapshots are `audit/phase04-dependencies-*.json`. Frontend/Rust/Dart advisory remediation is outside this backend phase and earlier findings remain open. Advisory counts are time-specific and are not unique CVE counts.

## Usage and drift review

No runtime imports were found in current source for backend http-proxy-middleware, uuid or node-cron, desktop three/@react-three/fiber, and several Flutter declarations including flutter_secure_storage/local_auth/flutter_inappwebview. The canvas particle effect uses ordinary canvas, not Three.js. Presence is not proof of secure token persistence or biometric enforcement. These are removal candidates, not confirmed safe deletions. root convert.js/convert.py duplicate work; fix-ico.py is host-specific. Do not remove them before confirming workflows/owner intent.

GitHub Actions use mutable major-version action tags and Trivy master; Rust stable and Docker tags are not pinned to immutable revisions. Flutter Gradle and release signing require repair before Android can have a reproducible dependency/build baseline. See BUG_REGISTER B02, B17–B23 and B44–B52, and ROADMAP for migration/recovery order.
