# README media

Original brand artwork was generated with built-in ImageGen; the exact prompt and provenance are in [source/artwork-prompt.md](source/artwork-prompt.md). The original raster is versioned. Logo/diagrams/type/animation layers are authored, with no stock imagery. The imagery is conceptual, not a security demonstration. Real captures and unavailable views are documented in [SCREENSHOTS.md](SCREENSHOTS.md).

Rebuild from the repository root:

```powershell
python -m pip install -r scripts/requirements-readme.txt
python scripts/build_readme_assets.py
python scripts/validate_readme.py
```

The pinned Pillow version and committed source make animation generation repeatable. Windows uses Segoe UI regular/bold; font names and SHA-256 inputs are recorded in manifest.json. On another host provide explicit --font-regular and --font-bold paths. Identical font inputs are needed for byte-identical output; fonts are not redistributed. The source artwork need not be regenerated by a model.

Hero:100 frames ×70ms =7 seconds. Footer:80 frames ×60ms =4.8 seconds. All motion functions are periodic and endpoint equality is asserted before export. A shared palette minimizes flashing/color drift; optimized GIF deltas reduce file size. loop=0 repeats seamlessly. Both have static WebP fallbacks. manifest.json records dimensions, timing, size and hashes.

README uses a standard picture/source reduced-motion alternative where the renderer preserves that media query. GitHub supports picture elements, but sanitization and client behavior can vary; the visible [static edition](../../docs/README_STATIC.md) is the reliable no-animation option. No autoplay preference is assumed or overridden. Text is repeated in Markdown/alt text, and diagrams have title/description elements and text documentation equivalents.

Palette: navy#071426, cyan#58e7f3, electric blue#2788ff; body text#f1f7ff and secondary text#adc3db on navy. No external fonts, scripts or foreignObject elements are required by the SVGs. Each linked repository asset is committed, with relative paths suitable for GitHub branch rendering.
